# PacheKing Music 🎵

Estación web para buscar, reproducir streaming y descargar música/videos de YouTube en MP3 y MP4 de alta calidad.

- Reproductor integrado en streaming sin anuncios.
- Descarga directa en MP3 (Audio) y MP4 (Video hasta 1080p).
- Desplegado directamente en GitHub Pages con alta disponibilidad global.
